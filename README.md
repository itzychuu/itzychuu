## About

I'm Vaishnav Shalikumar (Vaishnav S online), a third-year Computer Science Engineering student at Sree Buddha College of Engineering, Pattoor, based in Kerala, India.

I like building software that people can actually use. That usually means a full stack web app, a carefully designed interface, and a bit of AI or security thinking underneath. I care about UI/UX as much as the backend, and I'm happiest when a project solves a real problem rather than sitting in a tutorial folder.

Outside of coursework I take part in hackathons, lead creative and marketing work in student communities, and keep learning in public.

## Featured Projects

### ARCANA: Phishing Detection System
<sub>Cybersecurity · 24-hour hackathon project</sub>

A Chrome extension intercepts URLs and sends them to a backend that classifies each one as **Safe**, **Suspicious** or **Critical**. Suspicious sites can be overridden by the user, and critical sites are blocked. The backend combines ML-based URL classification, risk scoring and correlation of security signals, with caching and trust-cache logic to keep checks fast.

`Chrome Extension` `FastAPI` `Python` `Machine Learning` `Firebase`

### TalentPilot
<sub>AI recruitment desktop app</sub>

A hiring copilot that runs on local LLMs. It turns job descriptions into structured hiring profiles, parses resume PDFs, and scores candidates with semantic search. A multi-step LangGraph pipeline verifies resume claims and generates screening questions, and a live interview mode adapts follow-ups to each answer. It also ranks candidates and drafts recruiter feedback emails. Available as a Windows desktop app.

`Tauri` `React` `TypeScript` `FastAPI` `Ollama` `LangGraph` `FAISS` `Firebase`

### Gabriel
<sub>Emergency response · hackathon project</sub>

A cooperative emergency coordination system that links ambulances, hospitals and citizens in real time. It matches incident severity to ambulance capability, ranks hospitals by readiness and driving ETA, streams live vehicle tracking, and suggests alternative routes when time savings are significant. It includes a simulator for demoing a full emergency mission. I worked on the Python backend and database, and a teammate built the Next.js frontend.

`Python` `PostgreSQL` `Socket.IO` `OSRM` `Next.js`
